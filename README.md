# FinanceGroup-JSC
Счетоводна фирма с централа в София и офиси в Благоевград и Велико Търново. Работят с
чувствителни финансови данни и са задължени по закон да изолират счетоводната система.
Само одиторите от централата имат пълен достъп. Клоновите служители виждат само своите
клиентски данни чрез уеб портала (HTTPS). Всякаква P2P комуникация между клоновете е
забранена.
