Топология на s01 лаборатория

Конфигурацията е извършена чрез KVM виртуализация на Proxmox Ve 8.4.19

Създадени са следните мрежови сегнемнти:
    
    WAN 
        Мрежово пространсто: 192.168.0.0/24
        Представлява връзка към физическата локалната мрежа на host машината и към интернет
        Връзката към него се осъществява чрез linux bridge-а по подразбиране на proxmox vrbr0, към който е свързан и физическият интерфейс на host-а
    LAN 1
        Мрежово пространство: 192.168.100.0/24
        Връзката към него се осъществява чрез linux bridge на име LAN1
    LAN 2
        Мрежово пространство: 192.168.200.0/24
        Връзката към него се осъществява чрез linux bridge на име LAN2

Създадени са следните виртуални машини:

    Gateway
        hostname: gateway

        Заделени ресурси:
            1 vCPU
            1 core
            1024 MiB RAM
            5GB storage

        Свързаност:
            WAN
                осъществена чрез връзка към linux bridge vrbr0
                адрес:
                    получен чрез dhcp
                    192.168.0.208/24
                    
            LAN1
                осъществена чрез връзка към linux bridge LAN1
                адрес:
                    получен статично
                    192.168.100.1

            LAN2
                осъществена чрез връзка към linux bridge LAN2
                адрес:
                    получен статично
                    192.168.200.1
    
    Server
        hostname: server

        Заделени ресурси:
            1 vCPU
            2 cores
            1024 MiB RAM
            5GB storage

        Свързаност:  
            LAN1
                осъществена чрез връзка към linux bridge LAN1
                адрес:
                    получен статично
                    192.168.100.3
